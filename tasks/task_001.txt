<info added on 2025-05-25T15:08:33.674Z>
Implemented the iOS detection function in src/lib/utils/index.ts:

```typescript
export const detectIOS = (): boolean => {
	if (typeof navigator === 'undefined') {
		return false;
	}
	
	const userAgent = navigator.userAgent || '';
	return /iPad|iPhone|iPod/.test(userAgent);
};
```

The implementation includes:
- Boolean return value indicating iOS device detection
- Server-side rendering safety with navigator undefined check
- Regex pattern matching for iPad, iPhone, and iPod in user agent
- Consistency with existing mobile detection patterns
- Zero external dependencies
